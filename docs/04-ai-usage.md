# AI 使用、实际贡献与验证

| 参与方 | 本次会话实际贡献 |
|---|---|
| 候选人/用户 | 提供考核、选题、GitHub 仓库、CLI 范围与百炼配置；质疑决策证据并明确要求迁移 LangGraph |
| Codex 助手 | 生成实现、合成数据、测试和文档；执行安装、真实请求、证据检查、修正及 Git 提交/推送 |
| 运行时模型 | deepseek-v4.1-flash-1017 在 live 图节点中依据真实观察选择工具和结束状态 |

不冒称候选人独立手写或完成独立人工复核。候选人后续实际修改/验证应另增提交。Codex 精确后端版本未由会话工具提供，不猜测。

## 使用边界

AI 编写了代码、测试预期和资料，也通过工具执行真实验证；生成预期不等于实际结果，实际 Trace 单独保存。Mock 有预设动作，仅用于执行机制测试，不作为模型决策证据。
真实模型不知道 case 的 expect/read_docs，故障配置只由工具层读取。LangGraph 只分发模型返回的动作，不按用例编号决定业务路径。

## 实际修改和验证

0.1 原生版首轮曾出现无关冲突阻断；0.2 用户要求改用 StateGraph。迁移增加显式图状态、观察节点、检查点和观察到后续动作的关联文件。
首轮图版本 12/14：一次模型超时明确返回 incomplete；材料问题夹带未问期限数字。保留失败，增强通用输出约束，未修改预期来掩盖结果，再全量验证。
当前 44 个自动测试、14/14 Mock 与最终完整 live 14/14 通过。语义证据复核由 AI 执行，不冒称独立人类评审。

全部制度和对话为合成材料。密钥仅在被忽略的本机配置和 HTTPS 请求内使用，不进入图状态、文档或 Trace；错误脱敏，审计不输出密钥值。
小样本结果不代表生产可靠率；框架、结构校验与原文匹配均不自动保证全部语义正确。
