# AI 辅助范围、个人贡献与验证

## 如实归因

本 MVP 由候选人与 Codex 协作完成，不能表述为候选人独立手写全部实现。

| 参与方 | 会话中实际完成的内容 |
|---|---|
| 候选人 / 用户 | 提供要求和选题；选择题 3；创建关联 GitHub 仓库；确认 CLI 范围；提供百炼配置、凭证并确认最终模型；要求实施 |
| Codex AI 助手 | 分析方案；生成合成资料、代码、测试和文档；执行安装、测试、真实请求、Trace 复核、Git 提交和推送；发现并修正实际问题 |
| 运行时模型 | deepseek-v4.1-flash-1017 在 live 运行中选择工具、观察实际结果、补查或结束，行为见 Trace |

本次记录没有候选人自行修改源码或独立人工验收的证据，因此不虚报这些贡献。之后的实际修改和复测应新增提交与记录。
Codex 的精确后端模型版本未由会话工具提供，不猜测；它与运行时百炼模型是不同身份。

## AI 使用和验证

AI 生成了实现、测试预期及首版资料；通过工具执行命令并保存实际结果，不把预期当实际输出。
首轮 live 出现无关冲突阻断、无依据补充建议，AI 检查实际输出后修改通用提示词并增加回归约束，没有硬编码用例答案。
Mock 为预设动作，只验证机制，不能证明模型决策。真实工具结果和模型请求信息由程序保存。
语义复核由 AI 助手执行，不冒称人类复核；候选人独立复核及讲解能力仍需本人验证。
小样本结果不代表生产可靠率，采样、服务更新及语料变化均可能改变结果。

## 凭证与资料

制度与历史为合成材料。真实凭证只在 Git 忽略的本机配置和请求中使用，不进入代码、文档、Trace 或提交历史。
HTTP 错误中的当前凭证脱敏；审计只输出可疑文件名，不输出值。
